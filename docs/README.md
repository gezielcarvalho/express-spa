## Status

The repository is a TypeScript Express/MongoDB e-commerce API exercise with controllers and routes for common store entities, Swagger documentation, file-upload support, Docker assets, and a documented JavaScript-to-TypeScript migration. It does not include a real SPA frontend or automated tests.

Retain it as learning/reference material rather than a primary portfolio showcase; the Node/NestJS and FastAPI projects better represent current backend breadth.
