# Project charter

## Purpose

Practice server-side e-commerce API patterns using Express, MongoDB/Mongoose, route/controller/model separation, Swagger, Docker, and TypeScript migration.

## Verified current scope

- TypeScript Express API routes and controllers for users, products, carts, cart items, orders, and comments.
- Mongoose model layer and environment-based MongoDB connection.
- Swagger/OpenAPI endpoint, file-upload middleware, CORS, and Docker Compose assets.
- A documented TypeScript migration from an earlier JavaScript implementation.

## Boundaries

- The repository is API-only; it is not a complete single-page application.
- The package test command is a placeholder rather than an automated test suite.
- Authentication, data governance, authorization, production security, and operations have not been assessed as production-ready.

## Portfolio decision

Classify as a learning/reference archive candidate. Its migration documentation can inform other work, but it overlaps the selected backend showcase projects.
